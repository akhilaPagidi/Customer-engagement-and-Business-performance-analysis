
# Customer Engagement and Business Performance Analytics

##  Project Overview

Customer Engagement and Business Performance Analytics is an end-to-end data analytics project focused on analyzing customer behavior, purchasing patterns, customer satisfaction, and overall business performance.

The project uses **Python (Pandas), MySQL, and Power BI** to transform raw business data into meaningful insights and interactive dashboards.

##  Tools & Technologies

| Technology | Purpose |
|---|---|
| Python | Data preprocessing and cleaning |
| Pandas | Handling missing values, duplicates, data types, and date formatting |
| MySQL | Database creation, data storage, and SQL analysis |
| MySQL Workbench | Database management and query execution |
| Power BI | Interactive dashboards and data visualization |
| DAX | KPI calculations and business metrics |

##  Project Workflow

### 1. Data Cleaning and Preprocessing – Python (Pandas)

Used Python and Pandas to prepare the raw datasets for analysis.

- Loaded and explored multiple CSV datasets.
- Identified and handled missing values.
- Checked and removed duplicate records wherever applicable.
- Corrected inconsistent data types.
- Standardized date and time formats.
- Handled null values using appropriate techniques.
- Prepared cleaned datasets for database integration.

### 2. Database Integration – MySQL

- Created a relational database in MySQL.
- Created separate tables for customers, transactions, interactions, support tickets, customer reviews, and marketing campaigns.
- Loaded the cleaned CSV datasets directly into MySQL.
- Defined appropriate column data types.
- Established relationships between tables using common identifiers.
- Performed SQL-based data validation and analysis.

### 3. SQL Analysis – MySQL

Performed business-oriented analysis using:

- Aggregate functions.
- Joins and subqueries.
- GROUP BY and HAVING.
- CTEs.
- CASE statements.
- Window functions.
- Date and time functions.
- Views and analytical queries.

### 4. Dashboard Development – Power BI

- Connected Power BI directly to the MySQL database.
- Imported the required tables for analysis.
- Created DAX measures for business KPIs.
- Developed interactive dashboards.
- Used slicers, cards, charts, and filters to explore business performance.

##  Business Analysis Areas

1. **Customer Engagement:** Customer interactions, purchasing frequency, repeat customers, and engagement patterns.
2. **Business Performance:** Revenue, transaction volume, average transaction value, and product performance.
3. **Customer Satisfaction:** Customer reviews, support tickets, resolution time, and satisfaction scores.
4. **Marketing Performance:** Campaign impressions, clicks, conversions, conversion rates, and ROI.

##  Project Outcomes

- Successfully cleaned and prepared multiple datasets using Python Pandas.
- Integrated cleaned datasets into a MySQL relational database.
- Applied SQL queries to analyze customer and business performance.
- Connected MySQL with Power BI for reporting and visualization.
- Developed interactive dashboards to support data-driven business decisions.

##  Conclusion

This project demonstrates an end-to-end data analytics workflow, starting from raw data preprocessing using Python, followed by database integration and SQL analysis in MySQL, and finally interactive dashboard development in Power BI.

It highlights practical skills in data cleaning, database management, SQL querying, data visualization, and business intelligence.
